# 🚦 Indian Traffic Enforcement & Fine Collection Intelligence

### End-to-End Data Analytics Project | Excel → SQL → Python → Power BI

An end-to-end data analytics project focused on analyzing **traffic enforcement activity, fine collection, challan disposal, court workload, revenue flow, and data quality** using Excel, SQL, Python, and Power BI.

The project transforms raw traffic enforcement data into an interactive business intelligence solution that helps identify enforcement patterns, financial outcomes, court workload, pending cases, and data-quality issues.

## 📌 Project Overview

This project analyzes Indian traffic enforcement data to understand:

- 🚔 Traffic enforcement activity
- 💰 Fine collection and revenue
- ⚖️ Challan disposal and court workload
- 📊 Pending vs disposed cases
- 📅 Yearly and date-level trends
- 🔎 Enforcement patterns
- 🧹 Data quality and validation
- 📈 Key business and operational insights

The project follows a complete analytics workflow:

**Excel → SQL → Python → Power BI**

Each tool was used for a specific stage of the analytical process.

# 📊 Dataset Overview

The project uses traffic enforcement records containing information related to challans, fines, enforcement activity, disposal status, court-related outcomes, and dates.

### Dataset Highlights

- **Records:** 4,061
- **Data Period:** 2015 – 13 February 2026
- **Total Fine Amount:** ₹635.7B
- **Disposed Amount:** ₹229.7B
- **Pending Amount:** ₹406.0B

The dataset was analyzed across multiple dimensions to understand enforcement activity, financial performance, court workload, and data quality.
